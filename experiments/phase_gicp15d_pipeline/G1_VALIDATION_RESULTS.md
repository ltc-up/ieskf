## 3. R2：双图差分（本阶段的核心问题）

### 3.1 结果：没有复现 4.5 m 盆地分裂

同一帧、同一 Seed、同一 ROI，只把 Target 从 0105 换成 1013，两个解的 XY 距离 `d_map`：

|---|---:|---:|---:|---:|---:|---:|

| G1_SPECTRUM | 0.495 | 0.655 | 0.701 | 0.645 | 1.672 | 2.711 |
| G1_ROI_CROP | 0.478 | 0.661 | 0.758 | 0.634 | 1.663 | 2.295 |
| G1_NORMAL_GATE | 0.462 | 0.620 | 0.634 | 0.711 | 1.630 | 2.290 |
| G1_RECIPROCAL | 0.499 | 0.675 | 0.749 | 0.651 | 1.527 | 1.646 |
| G1_ROBUST_GM | 0.480 | 0.658 | 0.765 | 0.747 | 1.617 | 1.651 |
| G1_FULL | 0.454 | 0.674 | 0.718 | 0.618 | **1.418** | **1.657** |
| G1_COARSE | 0.477 | 0.661 | 0.749 | 0.703 | 1.853 | 2.294 |

**在历史故障窗口（395.6–398.8 s）里，8 个配置下两图给出的解最大只差 0.77 m，
没有一个进入 2 m 以上的不同盆地。** 也就是说：本轮**没有**在冻结输入上复现
"1013 图下约 4.5 m 错误吸引域"。任务书假设的该现象，在这批输入 + 这个 Seed 上不成立。

### 3.3 哪个机制真的有效

以 `W_ONSET` + 0105 的 `d_ndt p50/p95` 为唯一可比口径（同一 Target、同一 Seed）：

| 机制 | 变化 | 判读 |
|---|---|---|
| `SPECTRUM_FLOOR` 协方差 | 0.143/0.237 → **0.113/0.214**（−21% / −10%） | 唯一稳定的小幅正收益，单帧效应小 |
| ROI 裁树 | 0.143/0.237 → 0.143/0.237（逐帧完全相同） | **无差异**：此窗口内 120 m 圆柱没有把任何"最近邻"挡在外面 |
| 法向一致性 60° | → 0.159/0.323，且对应数 4,940 → 1,590（−68%） | **变差**；砍掉的对应里包含真实结构 |
| 互惠检查 | → 0.149/0.220，对应 4,940 → 3,706 | 中性偏负 |
| Geman-McClure `c=1 m` | → 0.151/0.211 | 中性 |
| coarse(1.5 m)→fine | → 0.142/0.237，`total_ms` 35→102 ms | 无收益且更慢 |
| `G1_FULL`（全部） | → 0.138/0.264，对应降到 1,142（−77%） | 组合不优于单项 |

**结论**：`SPECTRUM_FLOOR` 是本轮唯一有可测增益的机制；其余四项在本语料上没有正收益，
法向门限明确有害。这个"负面为主"的结果是本阶段最重要的产出之一。

## 4. 耗时（CPU，8 线程，单进程串行）

| 段 | R2 p50 | R2 p95 | 说明 |
|---|---:|---:|---|
| `align_ms`（一次 GICP） | 2.4–5.1 | 4.1–12.5 | G0 2.77，FULL 5.06 |
| `diagnostics_ms`（最终位姿重新线性化） | 0.7–1.5 | — | 开销量级 |
| `source_covariance_ms` | 0.6 | — | ≈2,800 点 |
| `total_ms` | 33–53 | — | **含每案例对 11.9 MB Target 重算 sha256（约 25–30 ms）** |
| Target 首次构建 | 载入 27 ms + 树 41 ms + 协方差 155 ms | — | 只做一次；后续 `target_cache_hit` |

**必须区分的两件事**：
1. 真正的配准是 **p50 1.6–5.1 ms**；本语料下 G0 已与 AW 一致地落在个位数毫秒。
2. `total_ms ≈ 33 ms` 的绝大部分是**离线台账完整性校验**（逐案例重算 Target sha），
   生产在线路径不会每帧重算。即便如此，`total_ms` 也**不能**被当作"满足 20 Hz/50 ms"
   的证据——因为它不含 Deskew、不含 IMU 传播、不含 15D 更新、不含 ROS 调度。
   严格 50 ms 完整周期资格：**NOT_VALIDATED**。

## 6. 本轮 G1 总判定

**PARTIAL**（不是 PASS，也不是 NO-GO）。

- 前端**确实**建成并在真实冻结点云上跑通，且与既有 GICP 基线数值等价（p95 8.6 mm）。
- 但在**指定的 395.7–397.1 s 故障窗口内，本批冻结输入没有重现 4.5 m 错误盆地**，
  因此无法证明"GICP 几何前端修复了该错误关联"。
- 唯一可归因的正面机制是 `SPECTRUM_FLOOR` 协方差（`d_ndt` p50 −21%），量级小，
  且只在 0105 单图上验证。
- 因此按任务书的原则，**不进入 G2 大规模闭环**；先补"能真正触发错误盆地"的同帧证据
  （需要 1013 图下真实种子偏离的输入，或 C4_22 的同帧成熟 15D prior/P）。
