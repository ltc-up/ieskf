# Minimal migration and rollback plan

No production changes were performed in AK. First real change should be an additive **candidate/decision diagnostic interface at the existing NDT process/publication boundary**, not replacement of the local filter.

Read-only module identifiers: lidar_ndt_v1/src/ndt_process.cpp, NDTProcess::GetNDTMatchingData and align result sites; lidar_ndt_v1/src/ndt_component_node.cpp, existing pose/score publication sites. These identify follow-up work only; no original code is copied into this repository.

1. Add NdtCandidateArray/SourceHealth export alongside existing messages: scan reference time, base/map contract, backend convergence, raw fitness, source LiDAR provenance, correlation group, UNKNOWN support/rank/modes where not yet implemented. Existing fields may not be silently promoted to valid covariance. Acceptance: every scan produces an auditable disposition; nonconverged, rejected, missing and stale are distinguishable; old outputs unchanged in shadow mode. Rollback: disable diagnostic publisher only.
2. Implement source manager and bounded pose history in independent ROS2 research node; validate timestamp/epoch/frame/lever handling and partial-LiDAR input contracts. Feed identical motion into existing Deskew. Acceptance: synthetic clock reset/delay/duplicate tests, one TF owner, exact no-map local parity; no feedback to production.
3. Add global correction shadow service with NDT/GNSS hypotheses and explicit UNKNOWN uncertainty. Acceptance: wrong Z/XY/yaw changes global candidate but zero local state/bias/odom modification; GNSS position recovery leaves unobserved yaw uncertain. Freeze transformation conventions and fail atomically on stale history.
4. Add map support + normalized directional diagnostics and bounded multistart candidate clustering. SDK feasibility and real costs are UNVERIFIED. Validate on small independently labeled static/map-hole/repeated-structure cases; false-confidence rate and no-source intervals matter more than smoothness. No Hessian scaling.
5. Independently establish GNSS datum/time/reference and NDT conditional error/selection correlation. Only then permit qualified global correction to downstream consumers. Define tolerable availability/error/latency using vehicle requirements before test; AK does not invent those numerical limits. Missing independent truth blocks an accuracy claim, not diagnostic recording.
6. Separately audit local Kistler/wheel observation physics, vertical observability and excitation for bias estimation. AJ wheel Z correction is not fixed by step3. Retain original15D research predictor as control. Selective/Schmidt is optional only after a concrete feedback need and dedicated nonlinear/statistical test.

Each step has feature flags, side-by-side logging and a last-known-good pipeline; on inconsistent clock/frames, unresolved modes or failed integrity tests disable the new consumer and publish degraded/unavailable global status. Never reset local velocity/bias to conceal a failure. Real closed-loop trial requires independent reference and bounded safety/rollback review; long replay is not the admission criterion. No direct deployment proposed in AK.
