# Passive surface evidence for preregistered 713 cases

Scope: a new entrypoint and matcher decorator only. Frozen kinematic runner, Source, previous-real-scan history, Target construction, NDT score/association/line search, validation and all returned matcher objects remain unchanged. No surface mask enters optimization or acceptance. Original continuous surface values remain NOT_LOGGED.

At each existing preregistered case, subclass the existing FixedHistoryPairProbe and temporarily decorate its underlying matcher. The decorator observes the actual baseline call and three existing diagnostic calls, without adding registrations. It computes source-facing source normals with the existing k=20 CPU helper, then transforms each Target from O into the immediately previous real scan's base using inverse(previous.O_T_base). Candidate current-source transform becomes inverse(previous.O_T_base) times candidate.O_T_base. Consequently ray origin is the actual historical scan/base origin, never arbitrary O zero. Normals stay in current Source base coordinates and rotate through that relative transform.

The separate log records case/frame, real historical anchor, source/Target identities, seed identity, candidate, counts with/without the signed ray-normal mask, 1.5/3 m occupancy diagnostic, normal/diagnostic cost and explicit failures. This is a source-facing GLIM-inspired variant, not upstream native dot>1 normal orientation, native VGICP surface validation or NDT Gaussian correspondence support. Occupancy counts may differ from DIRECT7 Gaussian valid pairs and must keep separate labels.

Tests must show invariance to an arbitrary O rigid gauge, a counterexample for the wrong O-origin ray, no mutation of input arrays or returned matcher objects, no additional match calls, and fail-open diagnostics preserving original algorithm result. Root reviews these tests and the entrypoint before enabling it in the new 713 runs. Existing experiments and current actual-time harnesses are untouched. CPU diagnostic cost is explicitly included in the serial callback and separately logged; it cannot establish production runtime.
