## B — RACECAR cited, experiments use another dataset

**Igor Cvišić, Ivan Marković, Sacha Vražić, Ivan Petrović (2025). Racetrack Rolling-shutter Stereo Visual Odometry and Dataset.** [AuthorPDF](https://lamor.fer.hr/images/50050805/2025-cvisic-rssoft-ecmr.pdf), [dataset/project](https://unizgfer-lamor.github.io/rt-dataset). The complete author PDF was subsequently obtained and read, including §IV and Table I. It cites RACECAR in related work but evaluates its own Rimac dataset: three laps at Grobnik and three at Navak, stereo rolling-shutter cameras, SOFT2-RS visual odometry and RTK/PPK evaluation. No online GNSS fusion or prebuilt point map is part of the visual odometry described. Table I reports mean relative translation0.43%, rotation0.20deg/100m, and arithmetic mean of sequence absolute RMSE1.95m. These are different metrics and data from our proposed BF study. Detailed runtime and a verified algorithm code release remain UNKNOWN here; the dataset project link is not proof of a complete code release. Useful lesson: model acquisition-time distortion and distinguish reference quality across datasets. No camera method or extra dataset is added to BF.
