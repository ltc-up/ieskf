# B implementation audit

Status: implemented research adapters and real CUDA synthetic end-to-end test; real continuous replay pending common runner integration. No production replacement or cross-line fusion.

`local_odometry.py`: strict previous scan B0, bounded rolling B-M, overlap B-K and pure-motion B-P. `bridge.py`: original-CUDA subprocess protocol, engineering validator and synchronous common-runner callback. `local_match_service.cpp`: independent local matcher initialized exactly once per request; destruction included in diagnostics. `run_stream.py`: standalone causal-frame consumer. `glim_diagnostics.py`: explicitly separate CPU diagnostics.

The native wrapper links the historical P0 library and its matching private headers. Current production headers have a different result structure and must not be combined with that library. First CPU compilation exposed absent result `valid_neighbor_count`/`inlier_count` fields; corrected by calling native `evaluateFinalQuality` and using its distinct source counters. This extra evaluation is included in timing. No native score, association, Hessian or line-search source is changed.

Original native options: resolution 1.5 m, DIRECT7, q50 gate enabled, maximum 35 iterations, step .2, step epsilon .01, relative objective epsilon .001, GLL window 3. Target voxel minimum points remains 6. The native target API is immutable: an existing matcher throws on repeated `setGlobalTarget`. The research wrapper constructs a separate local instance per frame, preserving the global map cache in the global instance.

27 CPU synthetic tests cover causal/unique scan processing, true-dt innovation gate, distinct support count, strict previous scan after rejection, U isolation, initial roll/pitch and gravity cylinder, Source immutability, dense Target rectangle distinction, B-P target bypass, multiframe capacity and signed surface check. All passed. A retained reference centroid implementation and checked21bit lexicographic pack optimization agree exactly, including SHA on float32/float64, negative coordinates, dense repeated voxels, boundaries, random input permutations and overflow fallback. Synthetic CPU grouping timing is saved separately and is not actual scan throughput. A synthetic six-frame CUDA test executed five actual registrations per B0/B-M/B-K; all proposals passed the frozen engineering validator. This establishes wiring, not reliable motion estimation on real data.

Validator v1 SHA256: `4164c300adf0f4db4504b9dd3e99aece38971e744e4f7d9909db3cffd5f198f0`. It does not use Fitness, reference trajectories, SPD or covariance shrinkage to certify correctness. Uncalibrated thresholds may reject useful corrections and admit wrong repetitive-structure peaks.

The second optimization caches immutable anchor occupancy and uses checked packed keys with vectorized support. The original keyframe policy is retained behind Config.fast_overlap=False. Tests compare 60-frame histories, O output and Target identity exactly for B-K and B-K-MR, including duplicate/negative/out-of-range points and rejection. Synthetic CPU overlap median 93.36 versus 9.98 ms is an operator benchmark, not real-data throughput or a strategy change.
