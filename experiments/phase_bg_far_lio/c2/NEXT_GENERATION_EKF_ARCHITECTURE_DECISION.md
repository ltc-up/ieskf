# 下一代生产EKF架构：当前决策

**继续保留15D单分支作为研究平台；生产替换NO-GO。**当前证据不足以把FAR最终横向收益归因于减少六个Bias状态。原生产6D及其默认Q/R、NDT、GNSS开关、TF/接口完全不变。

| 决策 | 状态 | 理由 |
|---|---|---|
| 保留三维p/v/姿态与15D Bias候选 | CONDITIONAL | banking、坡度、侧滑有三维需求，Bias物理合理；弱可观测性未获独立认证 |
| 直接采用FAR九状态替换15D | NO-GO | 不同匹配、辅助观测、P、轮速、延迟及重复信息；还发现源码Jacobian差异 |
| 新建受控9D研究 | 仅方案 | 同NDT/输入/R/时序，独立处理外置Bias不确定性；须另批 |
| 保留500ms回滚研究路线 | CONDITIONAL | 完整x/P与事件重传播，C1成本可接受；缺完整终态账本及关联重算一致性 |
| 优先审计生命周期/有效信息预算 | 优先 | FAR缓存重复、15D Legacy ×5/单接入确有代码证据 |
| 标定方向性R | 下一优先级方案 | 必须先固定信息预算与时间合同；不直接使用Native Raw或Fitness单阈值 |
| 移植FAR自适应R/裁剪/外推 | NO-GO直接移植 | 本次横向R未变，裁剪未触发，统计相关性及P收缩未认证 |
| 进入生产Shadow | 尚阻塞 | 需身份、时钟、观测终态、输出当前性、失败恢复、GNSS关闭隔离及资源上界 |

最小后续工作顺序（均需按用户授权范围另批）：先统一逐ID信息账本、记录FAR P/K/实际mask与补偿前后残差；审清15D沿用×5与生产队列的语义差异；再设计单因素R/信息预算冻结诊断与合法短窗。模型减维排在其后。不能直接除以5，不能把增加LiDAR权重一定有益当成既定结论：正常段观测更差时同样会放大错误。

生产兼容保留：map/base/IMU参考点合同，现有Wheel输入及失效处理、独立姿态接口、时间戳/延迟/当前状态输出、GNSS原开关及入口语义、初始化协议、状态质量与控制连续接口。YawBias不是3轴gyroBias，原6D功能不因15维模型存在就自动等价。GNSS关闭不允许经初始化后的在线其他模块绕入；本次共同初值是外部均值条件化实验，不是独立全局初始化。

当前15D生产Shadow阻塞：独立真实精度/垂向参考与Bias可观测性不足；Legacy R未标定，Native尺度与多峰正确性未解决；C1 Legacy无历史撤销/终态记录；旧匹配/Deskew不随迟到修正重算的相关性未认证；真实ROS/控制端端到端周期未证；不同轮速/倾角输入的公平性未控制。FAR全段50ms失败也不能作为新生产基准通过。

停止范围：本轮只读分析完成后停止。没有新9D、匹配、滤波重跑、Q/R/Bias/门限修改、数据下载或生产提交。后续矩阵与预算见[自适应R计划](ADAPTIVE_R_RESEARCH_PLAN.md)。
