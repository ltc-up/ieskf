# Phase U: Six-degree-of-freedom geometry factors

Use right-multiplicative SE(3) pose perturbations, retain complete information cross terms, and solve jointly with a prior using whitening. Geometry information is not an independently calibrated registration covariance. Repeated points, wrong correspondences and outliers remain explicit counterexamples. Historical synthetic correctness tests passed; do not rerun them to claim new experimental evidence.
