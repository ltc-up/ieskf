# Phase AY最终结论

**完成实际候选实现及三组完整单圈/连续三圈CUDA闭环；整体修复验收FAILED，不合入main，不替换原版。**

最有价值的候选是保留原CUDA-NDT与15D后端，增加真实原始光学XY速度，并在光学有效期间替代重复的轮速前向维度。其收益来自新的运动观测与完整状态反馈，不是缩小LiDAR R、放大P或人为增加增益。代码、数值测试、实际自身Deskew/匹配及回溯均已运行。

固定75ms工程参考下，XY单圈RMSE0.516665m，原版0.577097m；右弯3/9横向P95为0.567103/0.427361m，原版0.673964/0.667541m。连续三圈均4134/4134接纳，三个预定圈的XY差异均降低。**这些改善是CONDITIONAL，不是认证真实精度。**150ms参考下全局排序反转。

正常段8由0.343576退化到0.436548m，违背无正常路段退化要求。增加静态安装角状态没有解决，未继续用GNSS选择参数或地理门控。此处NDT自身与原版NDT相近且相对同一参考差异较大，不能靠“相信NDT更多”解决。未融合光学残差改善而参考位置恶化，说明当前多源物理一致性和工程参考之间仍不能相互认证。
