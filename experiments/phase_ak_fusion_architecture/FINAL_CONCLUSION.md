# Phase AK — final conclusion

**Recommend local15D inertial/motion estimation + NDT/GNSS global Map/Odom correction + explicit source integrity and ambiguity management.** Keep CUDA-NDT, Bosch, Kistler/wheel, available GNSS/RTK and existing Deskew. Do not replace the stack with LIO or FAR-LIO. This is a defensible feedback boundary, not an optimal joint probabilistic solution or a height-drift fix.

1. Architecture: prefer B over current A; C is conditional later work. Full local P is preserved. Bad map matches may still make global output wrong, but cannot directly reset continuous local pose, velocity or bias. Wheel-induced local height errors remain unresolved; missing height evidence must produce growing/unknown uncertainty.
2. FAR-LIO: reuse design patterns for typed source channels, freshness/health, vehicle-model separation and source-reported covariance recovery. Its2D5-state and3D9-state Euler/body-velocity EKFs are alternatives, not our15D right-error filter. IMU-handler stationary gyro bias averaging is not joint bg/ba inference. Its residual saturation and diagonal adaptive R must not be copied as certified rejection/calibration. External NDT can conceptually feed its odometry channel without GICP; integration is not built/tested here.
3. Coupling: reliable physical correlations should remain. Map/local service separation prevents direct feedback by construction. If partial-state updates are needed, formally derived Schmidt/consider covariance retains cross blocks; a projected observation alone still changes correlated dynamics. Do not zero P or use optimal-K shortcuts after masking gain.
4. NDT trust: separate support/coverage, directional degeneracy and global aliasing. X-ICP/SuperLoc suggest geometric-direction evidence; LF-GICP warns that regularized curvature can hide missing geometry. Export basis and provenance before claiming full covariance. Multiple seeds, independent GNSS and temporal consistency diagnose modes, but none alone proves a correct peak. Preserve AMBIGUOUS if evidence cannot decide.

Sensors: IMU propagates; Kistler measures validated sensor-frame velocity components; wheels provide conditional body motion with slip/scale checks; GNSS anchors observed absolute dimensions; NDT anchors supported map directions/hypotheses. No target-specific speed-only weighting evidence. FAR-LIO speed-conditioned bias/tire rules are source facts, not validated vehicle policy.
6. First real change: additive NDT candidate/health export at NDTProcess result and component publication boundary, then shadow source manager/global correction. Acceptance includes exact local no-map parity, atomic reasons, timing/frame/provenance checks and explicit wrong-global/continuous-local cases. Disable new consumers to rollback. See [migration](MIGRATION_PLAN.md) and [interfaces](DATA_FLOW_AND_INTERFACES.md).

Historical real aggregate evidence: AA early covariance contraction, AH/AI failures, AJ66/284 and4.137m wheel-Z correction. Actual accuracy, NDT peak rate/covariance, end-to-end timing and closed-loop readiness remain UNVERIFIED.
