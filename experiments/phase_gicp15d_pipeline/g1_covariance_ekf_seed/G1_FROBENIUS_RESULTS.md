## 4. 结论

1. **FROBENIUS 在本地图/本参数下没有收益，且明显更差**：
   p50 从 0.373 → 1.691 m，mean 0.880 → 2.561 m，优于 NDT 的帧数 5 → 3，
   并且使 4 帧由收敛变为不收敛。
2. 它**改善了条件数**（2.4e4 → 7.5e3），但条件数改善与位置正确**无关**——
   这是一条有用的反例证据。
3. `SPECTRUM_FLOOR` 同样无收益（1.275 / 1.945），与 G1-R 的结论一致。
4. 因此**保留 `G0_AW_EQUIV` 作为后续 15D 研究的主几何基线**，不引入 FROBENIUS，
   也不因本次结果调整任何 ρ / λ。

## 5. 为什么 FROBENIUS 会变差（机制解释，不作为定论）

`C_far = ||C0^-1||_F · C0` 只把每个点的协方差乘上一个**标量**。因此
`C_t + T C_s Tᵀ` 中两侧的**相对**权重由各自 `k = ||C0^-1||_F` 决定。
在 0.8 m 体素化的赛道云上，`k` 的分布很宽（邻域越"平"，`C0^-1` 越大，`k` 越小），
于是稀疏/平整区域的点被系统性地**放大**权重。而 small_gicp 的 `(1e-3,1,1)`
把所有点拉到同一尺度，反而抑制了这种由局部密度差异引起的偏置。
这与 G1 阶段"协方差模式是精度主导因素"的判断方向相反：**尺度归一化不等于更好**。
以上是观察到的相关性解释，未做受控分解。
