# AV implementation changes

1. **Packet versus smoothing likelihood.** Original: `engineering_R` defaults to5 even in unique-cloud research replay. New opt-in `ndt_packet_observation.packet_covariance` explicitly requests one-use packet semantics; the original function/default is untouched. Evidence: source queue compensation and information-form identity. Expected: restore the original packet budget without K manipulation. Actual short-run:40 true causal updates accepted; longer-run effect is evaluated separately. Risk: inherited score-to-noise mapping remains uncalibrated, including cross-cloud dependence.
2. **Full-state innovation safeguard.** New `InnovationGuardedPose` uses actual6D residual/H/P/R at the delayed historical instant; χ² limit is predeclared. It rejects the entire inconsistent measurement without changing the prior, otherwise delegates to unchanged ExternalPose. Full15D injection/Joseph/right-error reset, cross covariance and original state-domain guards remain. Risk: uncalibrated P/R can reject a correct observation; nominal probability is not a demonstrated false-alarm rate. Explicit full-pose API rejects unsupported projection rather than silently changing charts.
3. **Independent source qualification.** `matcher_integrity.py` persists the original authorized CUDA backend and Target, reuses AM geometry diagnostics, computes two fixed probe matches from the branch's own seed, and logs independent convergence/support/rank/local-cluster meanings. Exactly one central measurement is fused; no repeated-cloud information is added. Partial geometry, weak support, competing peaks and failed probes remain distinct. Risk: common wrong basins can pass all local probes; global correctness stays UNKNOWN.
4. **Explicit runner selection and rollback.** `run_candidate.py --policy legacy|single_use|guarded_single_use` imports the unchanged AR runner and overrides only research callbacks. Original mode and production defaults do not change. Input messages, own-state Deskew, own NDT seed, full history/P and delayed suffix propagation are retained. A2s observation-loss bound prevents indefinite unqualified integration. The same schema has additional diagnostic fields only; no production ROS publisher/TF owner is replaced.
5. **Startup lifecycle.** MapSupport's CPU index is built during the empty-source warm transaction, alongside Target startup. Initial guarded40 had a170ms first-frame CPU-index build but no missing update; that run is retained. Startup/preparation does not count as an observation. GPU/Target are not rebuilt per frame. Wall-time publication changes are reported separately from native-time accuracy.

No production/restricted source is copied. Original models, Q, wheel R, Bias model, vehicle transforms, NDT optimizer and runtime binaries are unchanged. None of these changes is justified by fitting GNSS errors.
