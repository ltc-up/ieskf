# Reproduction scope

Install dependencies using `python3 -m pip install -e .`, then `PYTHONPATH=src python3 -m unittest discover -s tests -v`. These are small independent migration checks, not reruns of historical numerical campaigns. Research objective/partition/constrained/posterior modules import without private data.

Real-input replay and plots require the local ignored archive. Set `IESKF_DATA_ROOT`, `IESKF_CONFIG`, and optionally `A2RL_ROOT`; no original production source is needed by the portable mathematical package. See docs/A2RL_INTEGRATION.md. Exact runtime environment and executed real-input commands are retained locally rather than published with internal results.
