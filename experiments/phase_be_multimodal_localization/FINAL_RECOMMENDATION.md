# Phase BE 首轮结论：审查与架构设计

本轮完成文献/关键参考源码审查、生产六状态/观测生命周期审计和统一数学设计；没有写新定位算法、没有运行BE新精度实验，没有修改生产NDT、滤波器、Q/R、TF或main。文献正确性、历史实测与未来设计分开标识，全文访问不足和现场配置未核实均明确保留。

## 本轮新增的确定发现

生产state_transition/measurement不使用vy，不能把Kistler发布vy当已融合。GNSS默认use_gps=0，但运行可被参数/服务改变，历史实际值未知。默认GPS1 converter将ENU天线位置直接发布入EKF，杆臂补偿注释；EKF不做参考点TF转换。另一路VectorNav虽有TF能力，所查配置目标是ant1且默认并非该EKF输入。因此未能证明GNSS已转换到map系后轴base_link，当前不得认定GNSS-on比较具备参考点资格。详细证据见GNSS_INTEGRITY_AND_FUSION.md。

GNSS开启、退出、恢复均沿用现有生产参数与流程；本轮不自动判断可信、不自动启用、不改FIX8分支。默认GNSS位置融合关闭，研究权重/seed/初始化也不得间接读GNSS。需进一步核验INS自身GNSS依赖，避免把“EKF位置开关关闭”夸大成完全GNSS独立。

## 如何保护正常横向修正

不按预测差大或几何弱就整帧拒绝。诊断保留XY-yaw耦合，强子空间候选投影仅作为未来反事实；真实侧滑会产生合理横向修正。不同盆地独立保留，以后续新扫描的共同条件证据确认，不均值化、不重复计数NDT/GICP相关证据。没有可靠判据就保持歧义，不人为调阈值造新算法。

## 实施顺序与未验证项

E0事件/参考点/参数契约 → E1方向+vy诊断 → E2共同输入双后端 → E3独立历史双支Shadow → 有证据才E4真实闭环 → E5恢复/生产可选GNSS对照。先做低成本可审计部分，不先重建系统。生产六状态与研究15D分别报告。

尚未证明：分雷达独立互补、GICP能解NDT错峰、双支选择延迟/概率校准、vy扩状态净收益、GNSS后轴转换和现场参数、恢复控制安全、BE完整50ms实时性。BD串行研究配置max70.674ms已说明现有历史不能支撑新增模块必然实时。当前推荐是有准入条件的研究顺序，非生产部署建议。
