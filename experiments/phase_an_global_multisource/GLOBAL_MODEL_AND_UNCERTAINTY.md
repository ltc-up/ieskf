# Global model, partial anchoring and uncertainty

GlobalManager owns C=T_map_odom, bounded local pose history,per-source received/fresh/converged/accepted reason,observed-dimension timestamps,last anchor,hypotheses and recovery counter. It has no15D state/P write interface. Each input must match map/extrinsic/reference/epoch contract; Header and arrival clocks are separate. Raw source health and observation eligibility are different facts.

PositionObservation is already map-frame BASE position after qualified antenna/datum/time conversion. It is not raw LLA or a6D pose. For qualified position dimensions D at τ, hold global rotation Rc and choose tc[D]=p_obs[D]−(Rc p_odom(τ))[D]. Other translation components and all rotation remain unchanged. This is non-Bayesian coordinate anchoring, NOT a Kalman update, optimal fusion or calibrated global posterior. No measurement information is accumulated by inverting score/Hessian. Covariance remains UNKNOWN_CORRELATION, and trusted_global=false even when operational state is GLOBAL_TRACKING. With no real qualified observations, no anchor is applied.

Optional independent bounded mode discrimination: transport old hypotheses to GNSS time using T_map_base(τ) inverse(T_odom_base(τ)) T_odom_base(t), then test only observed dimensions against externally justified deterministic joint mismatch bounds. Bounds must include candidate/relative-motion/GNSS/reference errors,not just GNSS sigma; use only when independent source evidence is established. No bounds are available for real inputs here. If old history has expired, skip pruning; do not reject an otherwise valid GNSS position. A surviving pose is still a hypothesis, not a certified6D posterior. One position does not resolve modes differing only in yaw.

INITIALIZING before usable evidence; RECOVERING on first qualified anchor after loss; PARTIAL when some global dimensions remain unobserved; GLOBAL_TRACKING requires separately qualified orientation plus fresh3D position in synthetic fixture; AMBIGUOUS retains competing modes; COASTING after500ms anchor age; UNAVAILABLE after2s or no anchor. These ages/two-fix reentry are declared operational settings,not data-calibrated probabilities. Each translation dimension expires separately; receiving XY cannot refresh missing Z. Historical initialization is not declared qualified absolute orientation. Real data exercised INITIALIZING/AMBIGUOUS/UNAVAILABLE only; remaining recovery states are synthetic verification.

NDT with unknown calibrated observation model participates in diagnostics/hypothesis management only. Same input group is processed once,never fused per seed. Unknown NDT–GNSS–local correlations are not assumed zero; no CI is used to hide uncalibrated marginals. For global pose error, Pg includes both marginal terms AND C/local cross terms; no global P is emitted without them. Local P remains the unchanged full15D model-conditional covariance. Missing vertical observations allow growth; no fixed Z,deleted cross terms or clipped vz.

Global velocity,if later published,must be expressed as Rc times local velocity with explicit frame/origin semantics. A change in tc is a global correction event,not physical acceleration. Core reports this semantic string and no differentiated jump velocity. ROS transport publishes only isolated research messages,no TF edge ownership.
