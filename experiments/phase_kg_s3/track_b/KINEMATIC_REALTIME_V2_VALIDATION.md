# Independent actual-time v2 engineering control

The original actual-time observer remains unchanged and failed early on both maps: eight/nine local commits, severe input delivery delay/expired Deskew history. Its worker cold local match was approximately 127/139 ms, with subsequent worker periods around 40–60 ms and additional main completion delay. Its dispatch timer omitted prior/history preparation; these original timings are not the complete 50 ms cycle. Receipts of Pose/health packets do not imply valid fresh Pose coverage.

Real raw-prefix component profiling, with cProfile overhead explicitly included for replay, measured single/dual Legacy ingestion P50 0.180/0.358 ms and P95 0.351/0.701 ms. At 302 buffered samples, repeatedly copying/validating the raw motion snapshot cost P50 1.366 ms and P95 1.411 ms. These observations motivate a bounded equivalence optimization; they do not establish the only cause of overload or promise that v2 will pass.

New separate v2 support keeps validated immutable MotionSample values and generation-caches duplicate checking. Each reader receives fresh containers and the unchanged frozen query algorithm. New v2 runner stops independent pure Legacy propagation only after the first local Pose/H initialization has formally committed via a threading.Event; pure is used solely for that initialization, never for subsequent motion. No worker H field is read by main. The original A0 replay, Source, historical Target, NDT, limits and motion math are unchanged. Cold initialization stays measured; there is no prewarming shortcut.

Full real-ledger equivalence checked 118,473 CDR-identity-verified IMU/Wheel events and all 7,798 scan intervals: complete old/new query records and frozen continuous motion deltas are exactly equal. Snapshot materialization P50/P95 improves from 0.163/0.173 ms to 0.00749/0.00882 ms in the normally pruned stream; this is component timing, not a complete cycle result. Nineteen CPU tests cover both original/new publication snapshots, concurrent commit/prune retry, late/future data, duplicate/changed identities, held gaps, physical SE(3) extrapolation and no fabricated Pose.

The v2 primary complete-cycle timer starts before removing the pending scan and preparing its historical prior, includes all worker and main commit costs, and separately preserves preparation, dispatch-to-commit and input-available-to-commit timing. Every output health reason is counted. Newly named full actual-time runs retain the old failures and all original thresholds. Actual v2 qualification remains pending execution and may remain NO-GO.
