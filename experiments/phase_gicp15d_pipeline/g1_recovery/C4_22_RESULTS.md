# C4_22_RESULTS — 真实历史错误 Seed 下的 GICP 行为

**NEW_EXECUTION**。标记：`HISTORICAL_SEED`（主实验本身）、
`TARGET_RECONSTRUCTED`（1013 ROI 重建，见 `SOURCE_RECOVERY_AUDIT.md` §1）、
`PROXY_REFERENCE`（评价基准，不是真值）。

## 1. 口径

- 评价基准 `PROXY` = `(-293.7944, -170.2990)`。它的来源是 narrow 变体的历史 CUDA-NDT final，
  该位姿在历史 CSV 中记为 `proxy_error = 0.1305 m`，即 PROXY 在这点附近 ±0.13 m 内。
  **这不是 GNSS 真值，是历史 0105 稳定 NDT 代理。**
- wide 变体的历史 CUDA-NDT final `(-293.5767, -173.1701)` 距 PROXY **2.9079 m**，
  历史 CSV 记为 `proxy_error = 2.9079`。这就是"历史错误分支"。
- `dPROXY` = GICP 最终 XY 到 PROXY 的平面距离。**越小越接近代理正确位置。**

## 3. 结论（主实验）

1. **G0（原始 small_gicp 等价前端）从真实历史 Seed 出发脱离了历史 NDT 错误分支。**
   wide：0.331 m vs 历史 NDT 2.908 m，差 2.58 m，且 GICP 的解与历史 NDT 解相距 2.658 m
   ——它不是"更靠近 NDT"，而是明确站到了另一边。
   narrow：0.440 m，而该帧历史 NDT 本身就在 0.131 m，因此 narrow 属于"两者都基本正确"，
   不构成恢复证据。
2. **`G1_SPECTRUM` 没有在 G0 之上提供增量**：wide 从 0.331 → 0.969 m（变差 0.64 m），
   narrow 从 0.440 → 1.314 m（变差 0.87 m）。
3. 因此本轮属于任务书 §七 **情况 A**：*原始 GICP 具有真实错误 Seed 下的困难盆地优势*，
   而**新增 G1 几何机制未获增量证据**（反而是负增量）。

## 5. 关键几何事实（不是正确性证明）

- **错误盆地存在且更"有支持"**：wide 的 −2 m 分支 inliers 3,295 > 正确分支 2,298。
  单看对应数会把错误分支判为更好。
- **但成本方向相反**：错误分支 cost ≈ 3.79e4，正确分支 ≈ 1.12e4（同目标、同 Source/Target、
  同配置、最终位姿重算），差 3.4 倍。本案例中成本是**可用但不充分**的判别量。
- 条件数：正确分支 1.1e4，错误分支未见秩亏，`rank_deficient = false`。
  因此"Hessian 正定"不能用来判对。
- 所有分支都 `converged = true`。**收敛不是正确性证据。**

## 6. 不能证明的部分

- PROXY 是历史 NDT 代理，不是独立真值；0.331 m 与 2.908 m 的差是**代理口径**下的结论。
- Target 是重建（98,214 vs 98,213 点），存在 3 点差异，可能轻微改变代价面。
- 只有单帧，不能外推到连续闭环；**不能**据此宣称 15D 闭环恢复。
- narrow 变体的历史 NDT 本来就正确，因此它只验证"不会破坏正确解附近"，
  不验证恢复能力。
