# 结论及停止点

1. **64/65为何收敛但更偏？CONFIRMED到路径层面。** 目标分别提升0.7337%/0.7235%，支持更多，沿不利纵向连续推进22/24步后满足步长+目标变化连续两次规则。收敛合同只约束局部数值变化，不包含参考误差；没有来回震荡或GLL回退证据。地图/重复结构具体贡献仍未独立分解。
2. **66卡哪里？** 最后目标相对变化0.000183已达标、接受步0.015232未达标；35次没有反向或回退，累计向不利纵向−0.505265m。目标阈值不是当前末步主要障碍。
3. **76卡哪里？** 最后步0.2、相对变化0.020851均未满足，最后10步持续封顶；支持+38.73%、目标+40.83%，累计不利纵向−3.577648m。不是GLL3反复缩步停滞，也没有观察到Newton两点过冲震荡。
4. **是否存在可证实震荡？** 119步score均增加、相邻尺度化方向均同向（余弦>0），无近两周期；关联ID未记录，集合身份周期UNKNOWN。
5. **弱几何下是否继续移偏？** 是。纵向为弱方向，64–76均持续向偏移区域优化；76途中局部曲率还增强。Hessian良好不能担保全局位置正确。
6. **35次不够是症状还是吸引盆地？** 已证明问题不只是预算不足：未截断的64/65也偏离参考。66/76在截断前向更高score但更偏区域推进；可称观测到“错误偏移的优化趋势”，不能凭35步严格证明最终吸引盆地、极值位置或无限迭代结果。不建议直接增加次数或放宽阈值。
7. **GLL3耗时主要来自哪里？** 本轮GLL回退开销为0次额外评估；align大部分是已启用PCL Fitness墙钟35.47–36.53ms。其余2.44–16.88ms含线性化、原生质量、SVD、trace等，细分UNKNOWN。不能把整段归咎GLL或把PCL计时当GPU事件时间。
