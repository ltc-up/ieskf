# V3 — Robust likelihood after V2's hard-gate lockout

V2 restored partial information through competing peaks, but actually stopped at1159/1468 frames after47 innovation rejections (1112 accepted). Several rejected frames had three agreeing converged hypotheses but base conditional NIS around60–70. An uncalibrated Gaussian χ² cut is not a correct-peak certificate; hard rejection can lock out recovery. V2 failure is retained, not hidden by the next candidate.

V3 preserves packet accounting, geometry, hypotheses, consensus projection, motion and Q. It replaces only hard innovation exclusion with an explicitly declared **finite-variance Gaussian scale-mixture likelihood**. Robust heavy-tailed filtering is motivated by [Roth et al., Robust Bayesian Filtering and Smoothing Using Student's t Distribution](https://arxiv.org/abs/1703.02428); the bounded-precision Beta prior and quadrature below are this research's stated model, not a claimed reproduction or calibration of that paper.

For a frozen linearized residual r=Hδ+ε, δ~N(0,P): ε|λ~N(0,R_packet/λ), λ~Beta(2,1),0<λ<1. No component is more informative than the source-supported single packet. The simplest increasing linear precision density2λ has finite marginal covariance E[1/λ]R=2R and a heavy tail; uniform precision would have infinite noise variance and is not used. This is an explicit uncalibrated contamination model, not a fitted scale, arbitrary P inflation or a direct replacement R multiplier.

For each precision, Sλ=HPHᵀ+R/λ; Kλ=PHᵀSλ⁻¹; μλ=Kλr. Cλ uses full15D Joseph with R/λ. Posterior precision weight is proportional to2λ*N(r;0,Sλ). Mean δbar=Σwλμλ and covariance Cbar=Σwλ[Cλ+(μλ−δbar)(μλ−δbar)ᵀ]. The between-mean term is required; simply selecting an effective R would omit latent uncertainty. Full SO3 injection uses δbar, and Jr(δbarθ) resets the complete Cbar. Conditional moment matching is exact to quadrature for the linearized model; nonlinear chart approximation and real covariance calibration remain unqualified.

Consensus W is applied once to r,H,R before marginalizing λ; ambiguous directions are not declared observed. All full15D correlations and existing attitude/Bias-domain rejection are retained. Large disagreement reduces posterior precision smoothly instead of creating a hard2s rejection wall. Global peak correctness remains UNKNOWN even with local agreement, and very weak conditional information cannot certify global localization.

A fixed128-point Gauss–Legendre rule with λ=x⁴ resolves small precision; no noise floor is tuned. The initial64-point numerical implementation missed the declared100m outlier convergence tolerance and was rejected before any GPU run.128 versus256 agrees to about1.8e−13 in that mean test. Original failed numerical log/snapshot is private. This is numerical quadrature refinement, not a GNSS/model-parameter search.

δbar=(ΣwKλ)r, but the effective matrix depends on r. The true local residual derivative additionally includes Cov_w(μλ,−Sλ⁻¹r); both are logged and finite-differenced. A conditional effective gain is not mislabelled the full nonlinear derivative. Scale posterior probabilities are model quantities, not calibrated correct-match probabilities.

Expected: reduce inappropriate hard-gate starvation while restoring packet information and withholding ambiguous combinations. Risks: residual bias can still be mistaken for heavy-tailed observation error; component correlations and physical scale prior are uncalibrated; local moment/chart validity and CPU cost need testing. V3 is frozen before any of its CUDA/GNSS evaluation, retaining the same strict repair screen and unchanged production defaults.
