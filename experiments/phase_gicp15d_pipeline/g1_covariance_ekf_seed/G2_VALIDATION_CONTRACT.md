# G2_VALIDATION_CONTRACT

本轮**不实施** G2。以下是从本轮证据导出的、可执行的 G2 验收合同。

## 1. 本轮证据允许与不允许的结论

| 允许 | 不允许 |
|---|---|
| G0 在 3 个相邻帧上从历史漂移 Seed 恢复到 0.18–0.39 m（代理口径） | "GICP 能持续恢复定位" |
| G0 在第 4 帧失败（4.39 m） | "GICP 在失败段普遍有效" |
| FROBENIUS / SPECTRUM 无收益 | "换个协方差就能解决" |
| Seed 在 1.65 s 内从 0.45 漂到 2.60 m | "15D 的 P / 交叉项已被验证" |

## 2. G2 的四个必测项（顺序不可颠倒）

### A. 数值等价（先做，不过则停止）

C++ 15D 必须与 Python `src/geometry_ieskf` 在**冻结输入**上逐项对齐：

- `InertialPredictor.model`：ZOH 偏置、`Eh=Exp(ω dt/2)` 求加速度、`E=Exp(ω dt)` 求姿态、
  `p += v dt + ½a dt²`、每子步 matrix→quat→matrix 重正交、`t += round(dt·1e9)`；
- `Q = diag(repeat([σg²/dt, σa²/dt, σbg²·dt, σba²·dt], 3))`，`P = F P Fᵀ + G Q Gᵀ` 后对称化；
- `inject` 用 `R←R·Exp(δθ)`，reset 用 `Br(δθ)=diag(I,I,Jr(δθ),I,I)`，**只做一次**；
- `Jr` 小角分支阈值 `a < 1e-5` 与 Taylor 系数；
- 注意 `Abg` 用 `jr(ωdt/2)`、而 `F[6:9,9:12]` 与 `G[6:9,:3]` 用 `jr(ωdt)` —— 两个参数不同；
- Joseph：`A=I−KH`, `A P Aᵀ + K R Kᵀ`, 再 `B·…·Bᵀ`, 再对称化；
- 事件驱动子步长（不是固定 100 Hz），`(header_ns, kind_rank, message_id)` 排序。

判据：同一冻结序列上，状态差 `≤1e-9`（相对）、`P` 差 `≤1e-9`（相对）。
**任一不达标即停止，不做连续闭环。**

### B. 观测融合（只换观测，不换 R）

同一 15D 内比较：

1. 原 CUDA-NDT 观测（历史）；
2. G0 几何观测。

R 固定为**已声明的工程值**（平移 0.25 m²、旋转 `(π/180)² rad²`，Phase AW 合同），
**不**用 GICP Hessian、**不**用 FROBENIUS 点协方差、**不**在两者间同时改 R。
FROBENIUS 只在 A 与 B 都通过、且 G1 另有正增量时才允许加入。

### C. 两种闭环必须分开报告

| 类型 | 起点 | 要证明的东西 | 判据 |
|---|---|---|---|
| **预防型** | 正常初始化 | GICP 能否减少地图失配导致的观测中断，避免 Seed 进入错误盆地 | 连续 `>2 m` Seed 偏差段数、最长观测中断时长、观测中断后恢复帧数 |
| **恢复型** | 合法漂移状态（因果重放起点） | GICP 观测被 15D 采信后，后续预测与匹配能否持续恢复 | 恢复后连续 `≤0.5 m`（代理）帧数、是否再次进入 `>2 m` |

两者**不得合并成一个准确率**。恢复型的起点若是 KG-S2 的
`conditional offline5scan graph`（`zeroBias/defaultP`），必须标明
`NOT_A_MATURE_15D_PRIOR`，不能冒充历史成熟 prior/P。

### D. 两类参数分离

- `GICP 内部点协方差`（3×3）→ 影响匹配目标函数；
- `15D 观测协方差 R`（6×6）→ 影响 ESKF 如何利用观测。

任何一次实验只能动其中一类，否则不得声称归因到某个机制。

## 3. 进入 G2 的门槛（本轮判定：未达到）

| 门槛 | 状态 |
|---|---|
| G1 存在可归因的正增量机制 | **NO**：FROBENIUS/SPECTRUM 均为负增量；G0 有优势但无"新增机制" |
| 捕获优势能连续多帧 | **PARTIAL**：3 帧成功 + 1 帧失败 |
| 有一个**可用于恢复型验证**的合法漂移起点 | **PARTIAL**：Seed 是匹配前请求 Seed，但无逐帧 P/IMU 记录，标注 `SEED_PROVENANCE_PARTIAL` |
| 数值等价合同已冻结 | **YES**（本节 §2.A） |

**结论：不启动 G2 实现。** 若强行启动，G2 只能验证"G0 观测 + 固定 R"是否比 NDT 观测更好，
而这正是 Phase AW 已经做过并给出 NO-GO 的实验（0.596 vs 0.577 m）。
在 G1 没有新机制的前提下重复它，不构成新证据。

## 4. 若要解锁 G2，最小增量工作

1. 取得**逐帧携带 15×15 P 与 IMU 传播记录**的漂移 Seed 段（不是 5-scan 离散图）；
2. 把失败段从 3 帧扩展到 ≥20 帧，并统计捕获率与失败模式；
3. 给出一个**在同一帧上同时改变点协方差与 R** 之外的单变量归因方案。
