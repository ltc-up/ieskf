# Publication whitelist

Allowed: independently authored research algorithms, portable tools, synthetic tests, generic configurations, redacted design/failure summaries. No original production source may be copied, adapted into public code, or vendored. Third-party libraries are dependencies, not bundled source.

Private: full original reports and source snapshots, real data and derivatives, private event-level sensor statistics/plots, trajectories, equipment identities, extrinsics, sensitive configuration, raw identity manifests and uncertain-origin material. Original records are never overwritten to create a public version. Public summaries are separate files.

Stage explicit public files only. Inspect the complete staged file list and text, reject private paths/data or binary artifacts, check file sizes and secret patterns, then commit and push without force. The ignored local data tree is never staged. Original project cleanup requires separate authorization.

The user subsequently authorized de-identified key numerical results, comparisons and failure summaries as part of self-contained phase reports. Publish non-reconstructive SHA identities and research-code revisions in phase manifest.json. Exclude exact event metadata, raw trajectories and unauthorized derivatives; aggregate authorization does not authorize private data payloads.
