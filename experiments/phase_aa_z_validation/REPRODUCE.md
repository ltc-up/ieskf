# Reproduce

Public: install the Python package and run `PYTHONPATH=src python3 -m unittest discover -s tests -v`. Use `python3 scripts/replay_diagnostic.py --help` and `python3 scripts/analyze_z_replay.py --help` for input interfaces. Full replay requires separately authorized private Sources, target, event/initialization contract and frozen configuration under IESKF_DATA_ROOT. Local detailed commands and manifests are intentionally excluded from GitHub.

This is a separate de-identified public summary. The immutable original/private AA reports, raw results and figures are retained under ignored `data/phase_aa_z_validation/`. No sensor-derived numerical results are distributed here.
